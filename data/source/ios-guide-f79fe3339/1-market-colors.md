# Market colors

The seven brand colors for every market, as hex. These are the same values as the `<code>-<role>` color tokens. The **Market palette** component shows each market's full set of 125 themed colors. Checked against `f79fe3339`: 78 markets, including Daily Herald (TDH), added since `e30ad2585`.

| Role | Source in code | Where it shows |
| --- | --- | --- |
| navbar | `navigationBarBackgroundColor` | Navigation bar background |
| navtext | `navigationBarTitleColor` | Navigation bar title and bar buttons |
| tabbar | `tabBarBackgroundColor` | Tab bar background |
| tabactive | `tabBarSelectedTintColor` | Selected tab icon and label |
| action | `paywallPrimaryActionColor` | Subscription links and buttons (the meter paywall purchase button has its own fill, `paywallViewPurchaseButtonColor`) |
| header | Style.json `cell-tertiary-headerBg` | Section-front header band |
| alert | `breakingNewsBannerBackgroundColor` | Breaking-news banner |
