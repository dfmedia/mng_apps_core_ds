# Bug report: what the design-system work found in the apps

Generated by `scripts/build_bug_report.py` from the app exports (iOS TroncKit `f79fe3339`, Android android-tribpub `1cfb069a6`), the Apps team answers (DREAMT-4718, DREAMT-4719) and the Android screenshots. Do not edit by hand.

Written for the Apps team. Each row is something that ships today and looks wrong: what it is, which markets, how we know, and a suggested fix. Contrast targets: text 4.5:1, icons and large text 3:1 (WCAG AA). The design system documents these values as shipped and does not change the apps; open questions stay in docs/MISSING-ASSETS.md.

**Summary:** 19 items: iOS 9, Android 6, Both apps 2, Style guides 2. 2 high, 9 medium, 8 low.

Priority: **High** = can't be read or used · **Medium** = fails contrast or misbehaves · **Low** = data or naming, no visible harm.
