# Icon names (combined iOS + Android)

Generated by `scripts/build_icon_names.py` from `data/icon-platform-map.json` (iOS TroncKit @ e30ad2585, Android android-tribpub @ 1cfb069a6). Do not edit by hand.

**What this is (DEC-17):** one shared name for each icon purpose, next to what each app ships today. Nothing is redesigned: each app keeps its own glyphs; only the name is shared. Names are proposals for Karl to review.

**Naming rule:** lowercase words joined by hyphens, named for what the icon does, not what it looks like. Prefixes: `tab-` (bottom tab bar), `enews-` (eNewspaper viewer), `brand-` (logos).

**Count:** 61 purposes → 60 names. Core: 32 · Core, per-platform value: 2 · iOS only: 25 · Android only: 2.
Names shared by more than one purpose: `saved` (Saved, Save star (special sections)).

Open questions for the Apps team are the numbers in docs/MISSING-ASSETS.md §1. The Android icon set has not been extracted yet (1.7).
