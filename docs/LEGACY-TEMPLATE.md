# iOS legacy theme template (acknowledged only)

Generated by `scripts/build_legacy_doc.py`. Do not edit by hand.

Seven iOS markets (BS, DP, HC, MC, OS, SS, VP) still run TroncKit's older theme template (Style.json, 60–61 keys) instead of the standard template the other 70 markets use. These values ship today, so they are recorded here. Per DEC-10 (Karl, 2026-11-03) they are **not** built in Figma, tokens or code, because the template should go away (IMPROVEMENTS TYPE-01). Designs for these markets use the standard styles. Source: the iOS style guide notes ("Legacy template (BS, DP, …): …").
