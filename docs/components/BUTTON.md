# Button

Generated by `scripts/build_button_tokens.py` from `data/source/button-shipped.json` and `data/button-decisions.json` (DEC-07). Do not edit by hand.

Core component with platform differences. Core holds the anatomy, states, shared tokens and the Figma component; the iOS and Android files hold only what differs (radius, height, label font, text link, pressed feedback).

## Scope

- Build: Primary: enabled, pressed (native platform feedback), disabled
- Build: Text link: enabled, pressed
- Later: Secondary
- Later: In-button loading (CTRL-02)
- Later: Continue button folded into Primary (DSC-24)

## Anatomy

- Container (fill = Brand theme action; disabled = button/disabled/fill)
- Label (uppercase; color = button/primary/label; disabled = button/disabled/label)
- iOS: 0.7 pt border in the fill color (all markets)
