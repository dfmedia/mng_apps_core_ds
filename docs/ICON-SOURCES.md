# Icon and graphic sources (DEC-26 inventory)

Generated by `scripts/build_icon_sources.py` from `data/source/style-guide-assets.json` (every file in the two Apps team style guides, downloaded 2026-11-25) and `data/icon-names.json` (DEC-17). Do not edit by hand.

**What this is:** every image the apps ship, as exported in the style guides, with the icon name it belongs to, whether it is the same drawing as another file in a different colour, and how the design system gets a vector for it (DEC-26: every icon and graphic is a vector, traced from what ships and checked against it).

**Count:** 356 files (Android 138, iOS 218). 16 are already SVG. 228 distinct drawings need tracing (121 icons, 75 market icons, 27 logos, 5 simple illustrations).

## Legend

- **shipped-svg**: Already a vector (shipped SVG): use as is
- **trace**: Trace from the largest shipped PNG, check against it at shipped size
- **review**: Photo-like or many colours: tracing will not match; Karl decides (keep raster or redraw)
- **keep-raster**: Photo: stays a raster image (not an icon)
- **component**: Rebuild as the Button component (text + icon), not an image
- **traced**: Traced to SVG and matches the PNG at shipped size (scripts/trace_icons.py)
- **traced-check-failed**: Traced, but the trace does not match the PNG: Karl decides
- **drop**: Not carried into the DS (never shown, or to be deleted from the app)
- **Colours**: mono = one ink colour; two-tone = two inks (e.g. white glyph on a coloured circle); multi = photo, gradient or texture.
- **Shape**: files with the same shape id are the same drawing; ×n = how many files share it.
